365 LETTERS — инструкция по запуску (Windows 11)

1. Установи Node.js LTS, если ещё не установлен: https://nodejs.org/
2. Создай папку C:\Users\ТВОЁ_ИМЯ\Desktop\365-letters и положи туда все файлы из архива.
3. Открой папку в VS Code: File → Open Folder.
4. Для простого запуска установи расширение "Live Server" в VS Code.
5. Открой index.html правой кнопкой → Open with Live Server.
6. Сайт откроется в браузере. Для проверки нажми на конверт.

КАК МЕНЯТЬ ПИСЬМА
Открой script.js и отредактируй массив messages. Первые 7 писем — примеры. Для 365 уникальных писем добавь собственные записи в массив. Не добавляй придуманные личные воспоминания — заполняй их только настоящими деталями.

ВАЖНО ПРО ОГРАНИЧЕНИЯ
- Эта версия хранит прогресс в localStorage конкретного браузера.
- Очистка данных сайта, другой браузер или другое устройство могут сбросить/обойти ограничение.
- Если отправить ссылку, любой человек с ней сможет открыть сайт и посмотреть код/тексты, включая будущие письма.
- Для реальной защиты нужны сервер, база данных и аутентификация или индивидуальный секретный токен. Сервер должен проверять дату и сохранять открытие; одного JavaScript недостаточно.
- Не добавляй в клиентский код пароли или секреты, которые нельзя раскрывать.

ПУБЛИКАЦИЯ
